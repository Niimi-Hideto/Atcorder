# AtCoder

競技プログラミングの精進リポジトリ。C++でAtCoderの過去問（ABC300以降）を解いています。

- 言語：C++17
- ACしたコードのみ管理
- ファイル名はコンテスト番号＋問題記号（例：`A460.cpp`, `B457.cpp`）

## フォルダ構成

```
Atcorder/
├── ABC_A/       # A問題
├── ABC_B/       # B問題
├── ABC_C/       # C問題
├── ABC_D/       # D問題
├── ABC_Re_A/    # A問題の復習・書き直し
├── ABC_Re_B/    # B問題の復習・書き直し
└── ABC_Re_C/    # C問題の復習・書き直し
```
