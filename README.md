# AtCoder

競技プログラミングの提出コード管理リポジトリ。

## 方針

- 言語：C++
- ABC300以降を解く
- ACしたコードのみ管理
- ファイル名はコンテスト番号（例：ABC300.cpp）

## フォルダ構成

```
Atcorder/
├── ABS/        # AtCoder Beginners Selection
├── ABC_A/      # ABCのA問題まとめ
├── ABC_B/      # ABCのB問題まとめ
└── ...
```
